# IEEE 7000-2021 — Model Process for Addressing Ethical Concerns During System Design

- **Kind:** framework | **Issuer:** IEEE Standards Association | **Region:** Global
- **Binding:** — | **Status:** Active
- **Effective:** Published Sep 2021

First IEEE standard for ethical system design: a value-based engineering process to address ethical values (not just requirements) during design. Value-based design process gives auditors a repeatable method — we can certify "values realised" evidence.
