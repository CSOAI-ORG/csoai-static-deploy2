# Project Moonshot (Singapore)

- **Kind:** framework | **Issuer:** Singapore IMDA + AI Verify Foundation + AISG | **Region:** Singapore + global
- **Binding:** — | **Status:** Active (open-source)
- **Effective:** Launched May 2024

An open-source adversarial robustness testing toolkit for LLMs/GenAI — prompt injection, jailbreak, and safety test suites with automated red-teaming. Adversarial test-category goldmine for our jailbreak/red-team measurement legs; MITRE ATLAS and OWASP-aligned.
