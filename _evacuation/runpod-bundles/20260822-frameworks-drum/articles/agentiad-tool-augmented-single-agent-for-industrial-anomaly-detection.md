# AgentIAD: Tool-Augmented Single-Agent for Industrial Anomaly Detection

- **Kind:** article | **Issuer:** arXiv preprint | **Region:** —
- **Binding:** — | **Status:** mined
- **Effective:** 2025

A single agent that augments industrial anomaly detection with tool use (calling vision tools, retrieval, reasoning) instead of a fixed model. Integrates the visual signal layer into the agentic loop where detection failures trigger tool escalation.
