# Singapore Model AI Governance Framework for Agentic AI

- **Kind:** framework | **Issuer:** Singapore IMDA / AI Verify Foundation | **Region:** Singapore + global (world-first)
- **Binding:** — | **Status:** Active (new)
- **Effective:** v1.0, launched Jan 2026 (Davos)

World's first model governance framework for agentic AI — multi-agent accountability, human oversight, identity/authorisation, and system resilience for AI agents. First-mover on agentic governance — we can be among the first measurement bodies to offer agentic-system attestation.
