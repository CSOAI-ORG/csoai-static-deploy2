# OpenAI Preparedness Framework

- **Kind:** framework | **Issuer:** OpenAI | **Region:** Global (frontier developer)
- **Binding:** — | **Status:** Active
- **Effective:** Beta Dec 2023; updated 2024–2025

Internal safety framework tracking catastrophic-risk categories (cybersecurity, CBRN, persuasion, model autonomy) through capability tracking, red-teaming, and readiness scores before release. Its readiness-score approach validates numeric, threshold-based measurement — exactly the product form we ship.
