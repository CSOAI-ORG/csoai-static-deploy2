# Google Secure AI Framework (SAIF)

- **Kind:** framework | **Issuer:** Google / Google Cloud | **Region:** Global
- **Binding:** — | **Status:** Active
- **Effective:** June 2023; expanded 2024–2025

Six-core security-first framework for AI systems: strong security foundations, extend detection/response, automate defences, harmonise platform controls, adapt controls to AI risks, contextualise AI risk to business. A security-first framework — complements our safety axes; useful for positioning measurement as a security control.
