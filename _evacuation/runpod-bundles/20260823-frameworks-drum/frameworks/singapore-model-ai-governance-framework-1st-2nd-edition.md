# Singapore Model AI Governance Framework (1st/2nd Edition)

- **Kind:** framework | **Issuer:** Singapore PDPC (Personal Data Protection Commission) | **Region:** Singapore + regional benchmark
- **Binding:** — | **Status:** Active
- **Effective:** 1st ed. Jan 2019; 2nd ed. Jan 2020

Asia's first AI governance framework — voluntary, sector-agnostic guidance covering internal governance, decision-making, risk/impact, and stakeholder interaction. The template for "model governance framework" series — shows how a small island state built global influence through voluntary frameworks we can map into measurement.
