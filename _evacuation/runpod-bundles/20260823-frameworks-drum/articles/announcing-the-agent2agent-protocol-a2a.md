# Announcing the Agent2Agent Protocol (A2A)

- **Kind:** article | **Issuer:** Google | **Region:** —
- **Binding:** — | **Status:** mined
- **Effective:** 2025

Open protocol (Apr 2025) for agent-to-agent interoperability — agent cards, tasks, and capabilities so heterogeneous agents can discover and delegate work to each other. Defines the agent-card format a registry needs so humans and AI can route tasks to the right agent, including across vendors.
