# Model Context Protocol (MCP)

- **Kind:** article | **Issuer:** Anthropic | **Region:** —
- **Binding:** — | **Status:** mined
- **Effective:** 2024

Open standard (announced Nov 2024) connecting LLM applications to external tools, data sources, and workflows via a JSON-RPC server/client architecture. The wiring layer that lets a research loop attach tools (web, code exec, DBs) and be attached to by humans and other agents; now an open governance project adopted across the industry.
