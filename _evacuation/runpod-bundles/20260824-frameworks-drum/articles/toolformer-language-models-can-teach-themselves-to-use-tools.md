# Toolformer: Language Models Can Teach Themselves to Use Tools

- **Kind:** article | **Issuer:** Schick et al. (Meta AI / LMU) | **Region:** —
- **Binding:** — | **Status:** mined
- **Effective:** 2023

Self-supervised learning of tool use: the model decides when to call which tool (calculator, search, QA) via a self-supervised loss on whether the call helps. The intellectual foundation for self-queuing tool calls in agentic loops.
