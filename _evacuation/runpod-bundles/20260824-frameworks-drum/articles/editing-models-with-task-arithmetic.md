# Editing Models with Task Arithmetic

- **Kind:** article | **Issuer:** Ilharco et al. (UW / AI2) | **Region:** —
- **Binding:** — | **Status:** mined
- **Effective:** 2023

Introduces task vectors and arithmetic (add/subtract) for composing and removing skills from models. Gives the merge-kit machinery its core operation: represent a skill as a vector and add it only when evaluation confirms it helps.
