# MCP-Zero: Proactive Toolchain Construction for LLM Agents from Scratch

- **Kind:** article | **Issuer:** arXiv preprint | **Region:** —
- **Binding:** — | **Status:** mined
- **Effective:** 2025

An agent that builds its own MCP toolchain from scratch, discovering and composing tools proactively. Shows the auto-extension pattern: the loop equips itself with new tools when current ones fail a task, then retries — tooling as part of self-improvement.
