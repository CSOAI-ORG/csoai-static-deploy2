# G7 Hiroshima AI Process — International Code of Conduct for Organizations Developing Advanced AI Systems

- **Kind:** framework | **Issuer:** G7 (Japan presidency) | **Region:** G7 + international
- **Binding:** — | **Status:** Active
- **Effective:** Oct 2023 (Hiroshima Leaders' Statement)

11-point voluntary code for frontier-AI developers: risk assessment, content provenance, incident reporting, model evaluations, cyber/security controls. Its "model evaluations" and "incident reporting" commitments map directly onto third-party evaluation and signed-card reporting services.
