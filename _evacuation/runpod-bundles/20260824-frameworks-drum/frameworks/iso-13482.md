# ISO 13482 — Personal Care Robots Safety

- **Kind:** framework | **Issuer:** ISO | **Region:** ISO/IEC
- **Binding:** no | **Status:** active
- **Effective:** 2014

Safety requirements for personal-care robots (mobile servant, physical assistant, person carrier) — the robotics safety standard for non-industrial robots; complements ISO 10218.
