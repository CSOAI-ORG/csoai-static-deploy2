# csoai (npm)

npm wrapper for the Council of AI measurement CLI. Shells the canonical Python `csoai`
(no reimplementation). Requires `pip install csoai`.

```bash
npx csoai check --entity gpt2 --pack art50 --json
npx csoai verify --record card.json
```
Exit 3 on a missing transparency predicate — a CI gate can require it. If the published
npm name is taken, scope it (e.g. `@councilof/csoai`) at publish time.
