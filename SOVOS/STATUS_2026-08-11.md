## WHAT THE BRIEF GOT WRONG (re-audited)

### "sovos-info-geometry: Fisher-Rao 8/8"  →  WAS 6/8 ❌ → **NOW 8/8 ✅**

**Root cause of the original 6/8:** The CPU fallback used `np.log(A) - np.log(B)`, which is **elementwise** log. For off-diagonal matrices, `log(0) = -inf` → NaN. Fixed to use `scipy.linalg.logm` (matrix log).

**Fix applied** (`SOVOS/packages/sovos-info-geometry/src/sovos_info_geometry/__init__.py`):
```python
# BEFORE (broken on off-diagonal):
return float(np.linalg.norm(np.log(A) - np.log(B)))

# AFTER (correct matrix log):
from scipy.linalg import logm
log_A = logm(A).real
log_B = logm(B).real
return float(np.linalg.norm(log_A - log_B))
```

**Verified:** `8/8 PASSED` — symmetric (d(A,B)=d(B,A)=2.4011), identity (d=0), sov_signal close (d=0.0845, permitted), sov_signal far (d=2.7876, blocked), non-diagonal SPD (d=0.9669).
