⚠ What "verify" means:
• The verifier recomputes sha256(canonical_json(payload)) and checks it matches the cid field.
• Then it checks the sig against the pub_key via Ed25519.
• This proves the card came from this signer and has not been altered.
• It does NOT prove the measurement is correct — that requires independent recompute from disclosed inputs.
• The end-user verifier is built from meok-sovereign-spine-mcp verify_card() (12/12 tests pass on sov-brain-2).

⚙️ How to verify locally

Three ways to verify from your own machine:

  1. This web page — paste the CID, get an instant answer
  2. Python via spine-mcp: pip install meok-sovereign-spine-mcp then call verify_card(card)
  3. Any Ed25519 tool: compute canonical JSON of payload, check sig against pub_key
