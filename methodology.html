Methodology — the GSPC instrument (versioned)

How Council of AI measurement works, versioned and dated. Every figure links to a signed card; every card names its method hash so a reader can tell exactly which method produced a number. This changelog is append-only — versioned, not an editable wiki. Citation spine: DOI 10.5281/zenodo.21991104 (concept) with the corpus version under it.

The split that makes it auditable

Deterministic core decides; LLM narrates; the harness never trusts the narrator. Verdicts come from ordinary code over frozen item banks. An LLM may narrate a verdict in plain English, but narration is presentation, not evidence — an auditor can replay the deterministic layer byte-for-byte.

The instrument

  • Axes: 14-slot registry, 13 measured. Public phrasing is only "13 measured of 14". One slot is gated/UNMEASURED and reported as such.
  • Corpus: 417 frozen statutory provisions (EU AI Act 126 · GDPR 99 · CRA 71 · DORA 64 · NIS2 46 · CSRD 11), hash-anchored and open.
  • Cards: id = sha256(canonical JSON of body), signature = Ed25519(id), prev links the chain. Verify offline: ./reproduce.sh <card.json>.
  • UNMEASURED: an axis not measured is UNMEASURED — never interpolated, never averaged over a gap, never hidden.
  • Quotability: a cell shows a number only when usable n with a computed interval exists (care: n≥100, per-class ≥30). Overlapping CIs render "statistically indistinguishable", never fake ranks.

Corrections discipline

Corrections publish in the same record as results — the corrections feed is the credibility. Corrections are supersession chains, never deletions; the honesty register is append-only. A number we cannot recompute is not a number we publish.
