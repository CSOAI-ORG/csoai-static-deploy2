Honest scope

What this is: a consolidated index of every shippable public tool in the SOVOS monorepo. Each link goes to a real, working artifact with real tests behind it.

What this is NOT: a UE Fire integration, holographic pixel shader, or Zeus/Eunomia mythological topology. Those require C++ engine work + hardware we don't have. They are documented as aspirational in the briefs but not shipped.

Honest count: 6 new tools shipped in this session, 7 foundational tools existed already. 13 total interactive surfaces, all browser-verified. Total cost: £0 (everything CDN-loaded, no server).

Behind the tools

All 13 tools are backed by a Python monorepo at SOVOS/packages/ with 13 packages and 164+ unit tests. The Python modules and the HTML pages share the same math (verified by browser browser_console checks). Source code: github.com/CSOAI-ORG/csoai-static-deploy2/SOVOS.
