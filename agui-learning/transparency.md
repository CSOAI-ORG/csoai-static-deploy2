## 2. What CSOAI Should Adopt — 5 Concrete Improvements for the AG UI Transparency chat window

1. **Always-present "nutrition label" panel** *(IBM FactSheets + HF model cards + Microsoft template)* — Pin a fixed, non-collapsible strip above the transcript with always-filled fields: **model identity/version · training-data lineage · evaluation method · known limitations · last-updated date**. Never freeform; every field must be populated or the UI shows "UNMEASURED" (consistent with CSOAI's honest-UNMEASURED posture) rather than silently omitting it.

2. **Machine-readable JSON backing every transparency claim** *(Google MCT + HF YAML)* — Store transparency as a versioned, signed JSON schema (fields for license, data, metrics, eval results), and render the chat window from that schema. This turns "we are transparent" into *data-backed* cards, and lets eval results appear as **numeric tables** (like HF's `model-index`) instead of adjectives.

3. **Art 50 applicability flag per response** *(EU AI Act Art 50 + AI Act Explorer)* — For each AG UI output, show a one-line strip: *"Art 50(2) synthetic-content marking applies → machine-readable label attached"* (or 50(1) human-interaction disclosure, 50(4) deepfake disclosure, or "N/A — not in scope"), each linked to the exact article/recital text. This operationalizes the 2 Aug 2026 obligation and makes CSOAI measurably compliant-by-construction.

4. **Quantitative transparency score + graded openness level** *(Stanford FMTI + MOF)* — Replace any binary "transparent" badge with: (a) a transparency score broken into upstream / model / downstream (FMTI-style, with the indicator count shown), and (b) a graded openness level (MOF Class I/II/III-style) with a visible 17-component checklist of what is actually released vs. withheld. Honest, comparable, and hard to greenwash.

5. **Signed Content Credentials on outputs** *(C2PA)* — Attach cryptographically signed provenance metadata to AG UI outputs (media and text), and surface a **"Verify"** affordance in the window that lets any reader check the credential independently. Because CSOAI is already a C2PA Contributor Member, this is native to the estate and turns the transparency *claim* into a *verifiable measurement* — which is exactly the neutrality asset CSOAI protects.

**Cross-cutting principle:** every improvement above converts transparency from *narrative* into *structured, signed, verifiable data* — the same direction as the 3KB signed-card / GSPC instrument. None of these require accounts or submissions to adopt as design patterns.
