## What CSOAI should adopt — 5 concrete improvements for the AG UI Creativity chat window

**1. Real-time semantic-distance divergence gauge, percentile-ranked, "first score only" (from DAT).**
Embed the user's (and the model's) novel keywords/ideas on the fly (GloVe / any embedding) and show a live "divergence" meter as the mean pairwise semantic distance. Rank it against a normed percentile, not a raw number. Crucially, adopt DAT's anti-gaming rule: **don't reveal the per-word distance breakdown until the round closes** — otherwise users optimise the gauge instead of thinking.

**2. Split the axis into two explicit channels: DIVERGENCE vs CONVERGENCE, and surface "convergence-by-scaling" (from CreativeBench + CPS evals).**
The chat window must show two labelled numbers — *divergence* (semantic novelty / idea-spread) and *convergence* (quality / coherence / correctness) — never one blended "creativity" score. Explicitly warn users that larger/longer responses tend to become *more correct but less divergent* (CreativeBench's "convergence-by-scaling" finding), so they can see when polish is eating novelty.

**3. Score novelty as QUALITY × NOVELTY with a verifiable/executable check (from CreativeBench + FOCUS).**
Replace "novelty alone" with a product metric that requires the idea to also be *valid* — an executable, grounded, or verifiable check (runnable code, factual grounding, testable claim). This makes "creative" structurally unable to hide hallucination, and lets the window flag "novel but unsupported" separately from "novel and sound."

**4. Live originality strip: distinct-n + self-BLEU + corpus overlap + self-plagiarism penalty (from FOCUS + originality detectors).**
Render an inline "novelty strip" under every response showing: distinct n-grams, self-repetition (self-BLEU), and n-gram overlap with a reference/memorisation corpus. Offer FOCUS-style contrastive self-plagiarism decoding as an inference-time steering toggle so the user can *actively reduce regurgitation*, not just observe it.

**5. Open-weight calibrated judge + percentile norms, multi-dimension report (from AGC-Bench + CreativityPrism).**
Serve creativity scores through a **bias-calibrated auto-judge** (Judge-Response-Theory-style calibration, e.g. an open-weight judge like AGC-Judge) rather than raw LLM-as-judge, and report **quality / novelty / diversity as three separate axes** — because novelty correlates weakly or negatively with the others (CreativityPrism). Add a percentile rank against a normed sample and a public leaderboard-style history, so the window shows *position*, not just a number.
