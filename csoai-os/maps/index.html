🚨 Operator note: The Google Maps API key is a credential. It is NEVER hard-coded in any HTML, JS, or Python file in this repository. The key is stored in keystone and injected at runtime. The Maps API call is made server-side (in the sovereign proxy), then OSCAL-stamped + SIGIL-signed + BFT-deliberated before being returned to the browser. The browser never sees the key.

Why sovereign Google Maps?

Standard Google Maps integrations expose: (1) the API key in the browser (vulnerable to abuse + quota theft), (2) the user's location to Google (privacy leak), (3) no audit trail (no SIGIL chain, no OSCAL proof), (4) no human oversight for high-risk geolocation decisions, (5) no BFT multi-stakeholder governance.

The Sovereign Google Maps integration wraps Google Maps as a sovereign MCP that:

  • Keeps the API key in keystone (never in the browser)
  • Routes every call through a server-side proxy that SIGIL-signs + OSCAL-stamps + BFT-deliberates the result
  • Enforces Care Floor 0.95 (geolocation precision respects citizen privacy)
  • Honors Article 14 human oversight for high-risk geolocation decisions (police surveillance, immigration enforcement)
  • Honors Article 50(2) C2PA marking for any AI-generated maps content

How to deploy

Step 1: Store the key in keystone

$ pbpaste | keystone set GOOGLE_MAPS_API_KEY
# paste the new Maps API key (HTTP referrer restricted + API restricted)
# keystone stores it in GCP Secret Manager + macOS Keychain

Step 2: Run the sovereign proxy

$ cd ~/clawd/csoai-os/maps/
$ keystone run GOOGLE_MAPS_API_KEY -- uvicorn sovereign_maps_proxy:app --host 0.0.0.0 --port 8042
# the key is injected as an env var; never appears in process listing

Step 3: Embed the widget on your page

<script src="https://csoai.org/csoai-os/maps/embed.js"></script>
