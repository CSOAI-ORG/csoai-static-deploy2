📋 8-Step Cert Issuance Workflow

Step 1 — Eligibility Check

Validate candidate's existing credentials. Citizen DID verified. Prerequisites completed for target tier.

POST /v1/cert/eligibility-check
Content-Type: application/json
{
  "candidate_did": "did:csoai:candidate-001",
  "target_charter": "01-csoai-charter",
  "target_tier": "practitioner"
}

Step 2 — Care Floor Verification

Real-time Care Membrane scoring at ≥0.95 threshold. Records recent signals, bias reports, transparency disclosures.

POST /v1/care/score
{ "candidate_did": "did:csoai:candidate-001" }
→ { "care_score": 0.96, "components": {...}, "eligible": true }

Step 3 — BFT Council Ratification

Ed25519 vote from 23/33 agents (or 33/33 + 5 human for Director tier). 72-hour deliberation minimum.

POST /v1/bft/propose
{ "type": "cert_ratification", "charter": "01-csoai-charter", "tier": "practitioner", "candidate_did": "did:csoai:candidate-001" }
→ { "proposal_id": "AMD-2026-XX-XX-XXXX" }

Step 4 — Ed25519 Signing

Once BFT ratified, sovereign substrate applies Ed25519 signature using sovereign root key + per-charter derivation key.

SHA-256(charter_content) → ed25519_sign(privkey) → sig:
9a7f83e6b2c4d1a5f8e0b3c7d5a6f8e1b2c4d6e8f0a2b4c6d8e0f2a4b6c8d0e2f4a6b8c0d2e4f6a8b0c2d4e6f8a0b2c4d6e8f0a2

Step 5 — OTS Bitcoin Anchoring

Submit signature + SHA-256 to OpenTimestamps calendar. Anchored to Bitcoin via proofof inclusion.

OTS.upgrade(pending_attestation, bitcoin_block)
→ { "ots_proof": "...", "bitcoin_txid": "0xabc..." }

Step 6 — SIGIL Chain Emission

Emit SIGIL with line format: C|council|cert|candidate_did|tier|Charter|Ed25519:9a7f...|OTS:0xabc...

Step 7 — Sovereign Passport Issuance

Generate certificate PDF + JSON with Ed25519 verification URL. Includes passport photo DID + biometric hash (optional).

Step 8 — Public Verification

Anyone can verify the cert at proofof.ai/verify/certs/{cert_id}. Returns SHA-256 + Ed25519 status + OTS anchor + BFT ratification record.
