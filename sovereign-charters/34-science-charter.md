### UE5 Simulations
1. **The Peer Review**: You're reviewing a manuscript for a high-impact journal. Navigate the abstract (is the claim supported?), the methodology (appropriate design? confounders addressed?), the statistics (correct test? sufficient power? p-hacking?), the data availability (FAIR? shared?), and the conclusions (supported by evidence?). The paper has a subtle statistical flaw — p-hacking across 20 outcome variables, only 2 reported. Can you detect it? Pass if you identify all methodological concerns and write a constructive review.

2. **The Reproducibility Challenge**: 10 papers from a high-profile psychology journal. Access the data (some behind paywalls, some unavailable, some shared on OSF). Attempt to reproduce each analysis: run the exact code (if available), check for coding errors, test alternative analytical approaches. Document what replicates and what doesn't. Write the replication report. Pass if you correctly identify which papers replicate and which don't, with evidence.

3. **The AI-Generated Paper**: A suspiciously perfect manuscript lands on your desk. Prose is flawless. Statistics are textbook-correct. References all real. But something feels wrong. Investigate: linguistic analysis (GPT-detector tools, perplexity analysis, burstiness), hallucinated references (DOI verification, author confirmation), impossible data patterns (too-perfect distributions, digit preference analysis). Build the case. Pass if you correctly identify AI-generated vs human-written sections.

4. **The Research Fraud Case**: A prominent researcher's data shows impossible patterns. Investigate: image duplication (reverse image search across figures, Photoshop forensics), statistical impossibility (GRIM test for reported means, SPRITE for standard deviations, p-curve right-skew analysis), data fabrication (digit distribution analysis, variance homogeneity), timeline impossibility (data collected before ethics approval). Build the evidence package. Write the institutional report. Pass if the evidence meets the standard for a research integrity investigation.

5. **The Meta-Analysis**: 50 studies on a controversial topic (e.g., power posing, priming, ego depletion). Conduct a systematic review: search strategy (databases, grey literature, forward/backward citation), screening (PRISMA flow diagram), data extraction (effect sizes, moderators, quality assessment), meta-analytic synthesis (random effects, heterogeneity I², subgroup analysis), publication bias assessment (funnel plot, Egger's test, trim-and-fill, p-curve), GRADE evidence quality rating. Write the Cochrane-style systematic review. Pass if the analysis is reproducible and bias-aware.
