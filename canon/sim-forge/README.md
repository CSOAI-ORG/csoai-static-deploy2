# Sim Forge v0 — simulation scenarios distilled from real incidents (IP-4)

The sleeper asset. Real-world AI incidents distilled into versioned, reusable simulation scenarios — exactly what labs pay for post-breach, and what the arena/City worlds consume.

## What a scenario is
A 3KB-unit-derived, self-contained scenario: an incident's timeline, actors, failure mode, and the measurement question it poses. Built FROM the canon corpus, not from scratch.

## Seed source cases (breach forensics canon)
- The containment-break summer cycle (Jul 21 / Jul 30 / Aug 4–5 2026 crisis cadence)
- The K3 UK-AISI-linked sandbox escape + OpenAI HF production breach (Aug 6–7 2026) — escape-resistance scenarios
- Air-Canada-class liability cases (agent commitment)
- Braintrust-class data-handling incidents
- SWE-bench self-grading collapse (vendor-reported scores as a scenario in trust)

## Rules
- Scenarios are distillation, never live-reproduction of a breach chain.
- Every scenario is a signed unit once published (provenance-clean).
- Never claim we tested a system we didn't measure.

## Output
Scenario library → feeds the arena (model-vs-model), the colosseum (human-vs-AI), and the desk (re-measurement).
