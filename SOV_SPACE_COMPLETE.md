## Stigmergy (Bee/Ant Communication)

### Pheromone Trails
- Success/failure signals that evaporate over time
- Strong pheromone = many agents succeeded here
- Weak pheromone = few agents tried or many failed
- Evaporation = old signals fade, new signals dominate

### Waggle Dances
- Structured messages from scout agents
- Scouts discover opportunities and communicate them
- Other agents read and act on these messages

### Pollen Deposits
- Knowledge fragments agents carry and deposit
- Cross-fertilization between families
- Knowledge spreads through the hive

## Spine Drum (Heartbeat)

```
Beat 1: Evolve stigmergy (pheromone decay, pollen flow)
Beat 2: Run EAT cycle (benchmark, improve, transform)
Beat 3: Update knowledge (absorb new data, consolidate honey)
Beat 4: Sync across nodes (Mac ↔ Oracle ↔ Kaggle)
Beat 5: Generate sigil (record state in chain)
```

Like a heartbeat:
- Systole = active processing (EAT, benchmark, train)
- Diastole = rest and consolidation (sync, absorb, record)

## G-Space (Graph Neural Network)

G-Space is where the GNN lives inside SOV-space. It's the "graph brain" that connects all families, clans, and knowledge nodes.

When SOV enters an arena/competition:
1. G-Space spawns swarms of family agents
2. Each agent runs internal simulations in their J-space
3. Agents dream and evolve in C-space
4. BFT quorum votes on best outcome
5. Fluid honey memory updates in real-time
6. The winning strategy emerges from clan consensus
