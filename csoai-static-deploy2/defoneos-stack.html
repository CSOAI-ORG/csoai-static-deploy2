0

Layer 0 — Protocols

Every connection in DEFONEOS runs through open protocols. No proprietary protocol. No vendor lock-in. The protocol layer is what makes the system defensible against single-vendor risk.

  • MCP — Model Context Protocol. Anthropic's open standard. JSON-RPC 2.0 over HTTP. 30 DEFONEOS MCPs registered.
  • A2A — Agent-to-Agent. Google's open spec. Inter-agent task delegation.
  • x402 — Coinbase payment protocol. Per-call pricing for AI services (article50_passport, federated_rag_call).
  • IBC — Inter-Blockchain Communication. Cross-chain SIGIL anchoring (Bitcoin + optionally Ethereum, Cosmos hub).
  • DID — W3C Decentralized Identifier. Sovereign identity (CSOAI-ORG-001, etc.).
  • SIGIL — DEFONEOS's own audit protocol. Ed25519 signed receipts.
  • HTTP/3 — QUIC-based transport. Faster, encrypted, multiplexed.
  • WebSocket — Real-time bidirectional. Live SIGIL feed.
  • Matrix — Decentralised messaging. Hive-to-hive coordination.
  • IPFS — Content-addressed storage. SIGIL receipt archive.

Components: 10 open protocols · 0 proprietary · Auditable: 100%

Layer 5 — SIGIL Chain (the proof)

5

Layer 5 — SIGIL Chain

Ed25519-signed cryptographic receipts for every AI decision. Immutable. Hash-chained. Periodically anchored to Bitcoin blockchain. 49,127+ receipts and counting. Legally-defensible audit trail that any regulator can verify in 4 commands.

The SIGIL chain is the technical realisation of the Constitution's Article 8 (Cryptographic Proof). A regulator receives a SIGIL receipt → verifies the Ed25519 signature against CSOAI-ORG-001's published public key → verifies the receipt's hash chains to the previous receipt → verifies the chain anchor at the indicated Bitcoin block. If all 4 pass, the receipt is genuine. If any fails, the receipt is not. The proof is mathematical, not institutional.

Algorithm: Ed25519 · Receipts: 49,127+ · Anchored: Bitcoin OP_RETURN · Public verifier: proofof.ai

Layer 6 — BFT Council

Byzantine Fault Tolerant governance. 33 hive nodes. 22-of-33 quorum required for sensitive actions. No single AI agent can take unauthorized action. Mathematical proof of consensus on every escalation.

BFT is the same algorithm class that runs Tendermint (Cosmos), HotStuff (Facebook's Libra), and SimBlocks. The DEFONEOS BFT variant is optimised for defence tempo: sub-200ms consensus on routine actions, sub-2s consensus on escalations. Quorum 22-of-33 means 11 nodes can be compromised (or simply offline) without halting the system. BFT is the reason a single rogue SIGIL receipt cannot corrupt the chain.

Honesty Register — Build vs Buy Caveats

  • Integration cost £170K is CSOAI's actual, not a marketing number. This is the time-cost of integrating 12 OSS components into a working stack over 4 months. It excludes ongoing operational cost (compute, storage, salaries) which adds ~£400K/yr.
  • "Buy equivalent" figures are upper-bound estimates. Proprietary stack prices vary widely by customer. Palantir Defence list price is $1M+/yr per site; UK MOD has reportedly negotiated substantially below this. The £9.2M/yr figure assumes list prices.
  • OSS components have hidden costs. Open source does not mean free. Maintenance, security patches, upgrades, and integration engineering all cost money. The £170K integration figure understates total 5-yr cost-of-ownership; full TCO analysis at /defoneos-pricing.html.
  • UE5 free-for-defence is conditional. Epic's UE5 licensing for defence requires a custom EULA signed by Epic. CSOAI has not yet signed (the £2M saving is contingent on this).
  • Compute costs not included in TCO. The £17.4M saving is licence-fee only. Compute (M4, M2, GCP VM, UK bare metal) costs ~£120K/yr and is on top of the licence-fee saving.
  • illustrative vs live: The 12-component stack is live. The £170K integration cost is real (CSOAI's actual spend, not modelled). The buy-equivalent figures are upper-bound estimates. All numbers are verifiable against the CSOAI finance ledger on request.
