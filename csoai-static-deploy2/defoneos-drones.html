🧠 Mava Swarm Intelligence

Mava is InstaDeep's open-source multi-agent RL framework. DEFONEOS uses Mava for autonomous swarm behaviours:

IPPO

Independent PPO — each drone learns independently. Simple, robust. Good for ISR grid search patterns.

MAPPO

Multi-Agent PPO — shared critic, decentralized actors. Coordinated attack patterns. Flocking with collision avoidance.

QMIX

Monotonic value factorization. Optimal for coordinated attack on defended positions. SWARM TTPs.

SEAC

Shared Experience Actor-Critic. Off-policy. Data efficient. Good for rare-event training (jamming, GPS denial).

🗺️ OpenAthena — Drone Geospatial Intelligence

OpenAthena enables consumer drones to produce accurate geospatial intelligence. DEFONEOS integrates it for ISR and targeting:

🎯 Target Location

Extract precise GPS coordinates from drone imagery using gimbal angles + DEM data. Accuracy: 3-5m CEP.

📸 Orthomosaic

Stitch 100+ drone images into georeferenced orthomosaic. Output: GeoTIFF. Used for BDA and mission planning.

🌍 Cesium Integration

Stream drone GPS + gimbal → Cesium globe. Real-time ISR feed in 3D COP. Click-to-target.

📏 Mensuration

Measure distances, areas, heights from drone imagery. DEM-corrected. Building height estimation for urban ops.

Deployment: Passive Acoustic Mesh

1

Deploy 3+ microphone arrays

Raspberry Pi 4 + 4-mic array. Solar powered. Mesh network (WiFi/LoRa). 500m spacing for triangulation.

2

Stream audio to edge processor

Raw 16kHz mono → edge inference. Jetson Nano / Coral TPU. Batear model classifies drone type.

3

Triangulate bearing

3+ bearings intersect → drone position. Accuracy improves with more arrays.

4

Push CoT EVENT

Batear detection → CoT event (type a-n-A-C-F) → FreeTAKServer → all ATAK clients alerted.
