# csoai-council-ledger — signed provision-conformance receipts

Measure conformance of an AI output to a **frozen regulatory provision** (EU AI Act Art 50 ready), emitted as an **Ed25519-signed receipt** anyone can verify offline. Deterministic predicates — never a model opinion.

## CLI
```bash
pip install csoai-council-ledger
council conformance EU-AI-Act-2024-1689-Art6
council market        # live East/West index context (9 indices + pair-gap)
council humanai       # human vs AI scored vs measured truth
```

## Three surfaces, never blended
- Provision-conformance (MEASURED, deterministic)
- Market context (MEASURED, reported alongside)
- Human/AI (REPORTED, scored — never ranked for money)

## Firewall
Nobody ranked pays. Humans never pay. Independent, neutral, tamper-evident.
