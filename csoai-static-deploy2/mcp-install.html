📦 One Package — 9 Tools

meok-sovereign-globe-mcp is the unified visual MCP. It wraps every sovereign 3D / globe / city / arena / colosseum surface as iframe-able tools that any MCP client (ChatGPT, Claude, Cursor, Copilot, Gemini) can render in chat. End-users install once; the AI platform handles the rendering.

render_globe
Returns iframe-able 3D Cesium globe with 33 sovereign hive markers, open-data layers, hive connection lines.
render_world
Returns iframe-able photorealistic 3D Earth (world-3d). CC0 + MIT layers.
render_city
Returns iframe-able 3D Council City (sov-city-3d) — 33 clan districts, AI swarm skirmishes, human participation meter.
render_arena
Returns iframe-able live arena dashboard. Real rounds from /api/sov-arena/rounds.jsonl streaming.
render_colosseum
Returns iframe-able colosseum / SOV33 multi-arena hub.
render_bft33
Returns iframe-able 33-voter BFT council live view (f_bft=10, quorum 23/33).
get_live_state
Returns JSON: arena rounds count, agreement rate, OpenTTD tick, clan activity, health.
list_surfaces
Lists all 9 visual surfaces with URLs and types.
install_for_platform
Returns the exact install command/snippet for any of 5 AI platforms.

⚠ Honest constraints:
• MCP tool calls are platform-dependent. Some AI platforms render iframes; others show text + URL only. We return BOTH in every tool so both work.
• The 3D visual surfaces are served from csoai-site.pages.dev (Cloudflare Pages). If that goes down, the tool returns the URL + a graceful fallback.
• Live arena rounds are honest measurements — the dashboard displays UNMEASURED labels where data is below usable_n=30, never zeros.
• ChatGPT's MCP support is newer and limited; for full visual embedding, use Claude Desktop, Cursor, or VS Code Copilot.

📋 Why MCP (and not a website)

The user asked: "end users aren't going to want to go on my website — they're all already in the AI platforms, social media, AI characters." Exactly right. MCP (Model Context Protocol, donated to the Linux Foundation Dec 2025) is the standard that lets AI platforms call our tools. Our job is to be the substrate they call into — not to compete for traffic with the platforms themselves.

We ship 9 iframe-able tools. Any AI platform that supports MCP (ChatGPT, Claude, Cursor, Copilot, Gemini, VS Code, Continue.dev, JetBrains, and growing) gets the full sovereign OS as a native tool. The end user sees 3D inside their chat. We don't need them to visit csoai.org — but if they want the full sovereign-os page, it's there too.
