Why Assemble, Don't Build

The UK MOD Procurement Act 2023 §22(1) "prioritise open standards and reusable components before commissioning custom builds" sets the doctrinal baseline: sovereign software is not sovereign if you pay $50M to a foreign vendor to build it for you. DEFONEOS flips that. We assemble 12 battle-tested open-source projects, integrate them with a 10-layer sovereign kernel, wrap every output in Ed25519-signed SIGIL receipts, and ship at 1% the cost of building from scratch.

This page is the canonical architecture diagram of that assembly — what each layer is, what open-source project powers it, what's the licence, what would it cost to build instead, and what UK compliance framework it maps to. The whole stack is reproducible by a 2-person team in 4-6 weeks on commodity laptops. No vendor lock-in. No paid APIs. No data ever leaves UK / EU jurisdiction.

Top of the stack = where the warfighter logs in. Bottom = where UK compute runs. Right side = where SIGIL evidence is written.

Layer 0 — Protocols & Identity

Components: MCP (Anthropic, Apache 2.0), A2A (Google, Apache 2.0), x402 (Coinbase per-outcome payments, MIT), W3C DID (BSD-3), SIGIL (CSOAI, Apache 2.0 — Ed25519 hash chain), HTTP/3 (RFC 9114), WebSocket (RFC 6455), Matrix (Apache 2.0), IPFS (Apache 2.0 / MIT), IBC (Apache 2.0).

What it does: Every component speaks open protocols. No vendor lock-in. Sovereign identity via DIDs. UK / EU / AU / US sovereign instances all federate A2A-style.

Build-from-scratch cost: £2.5M, 24 months. License: Stdlib + Apache 2.0 + MIT.

🪞 Honesty Register

The "£17.4M saved" figure is a build-vs-integrate counterfactual. It assumes a typical UK defence contractor would need 60 months and £17.4M to deliver equivalent capability in-house. This is based on average UK MOD cost-per-engineer (£150K/yr) and Scaled-Agile-large-team maths, not a specific quote.
