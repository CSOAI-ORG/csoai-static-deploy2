2. Live SIGIL Chain Verification

SIGIL is the immutable, Ed25519-signed hash-chained receipt log. Every MCP call emits one. Every BFT vote emits one. Every defensive decision emits one. Verification protocol:

# Verify the latest SIGIL receipt
curl -X POST http://localhost:3101/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"sigil_chain_status","arguments":{}}}'

# Verify a specific receipt by digest
sigil_verify --digest 91ea285fda8e0f2dab7dcc70db257c898fd9c78573c12e84a7977748273ee181

# Walk the chain backwards (verify ancestor)
sigil_walk --steps 100

# Anchor proof to Bitcoin (optional, for legal-grade)
sigil_anchor --chain bitcoin --receipt_id latest

Receipt anatomy (what one SIGIL looks like)

{ "line": "P|opus|csoai-defoneos|verify-tick-43", "ts": "2026-07-06T16:30:00Z", "digest": "91ea285fda8e0f2dab7dcc70db257c898fd9c78573c12e84a7977748273ee181", "prev_digest": "e5c38d8c8f8da001...", "signature": "ed25519:7f3c8a4b2e1d...", "actor": "opus-agent", "compartment": "csoai-defoneos", "action": "P", // P = publish, V = vote, M = mcp_call, Q = query "tier": "free" }
