## PRICING MODEL ANALYSIS

### How Vendors Price (Revenue Drivers)

| Model | Vendors Using | Revenue Driver |
|-------|--------------|----------------|
| **Per-seat / per-user** | ServiceNow, LogicGate (power users), OneTrust (admin users) | Headcount growth |
| **Per-framework** | Vanta, Drata, Secureframe, Sprinto | Compliance expansion |
| **Flat annual by tier** | ZenGRC, Hyperproof, AuditBoard | Organization size |
| **Per application/module** | LogicGate, MetricStream, IBM OpenPages | GRC maturity expansion |
| **Usage/consumption-based** | Datadog, Dynatrace, Arize, Langfuse | Data volume growth |
| **Per device/endpoint** | CrowdStrike, Jamf, Wiz | Device fleet growth |
| **Per vendor monitored** | UpGuard | Supply chain growth |
| **Bundled (software + audit)** | Thoropass | One-stop-shop premium |
| **Enterprise flat-rate** | Credo AI, FairNow, RSA Archer | Contract value |

### Revenue Architecture Insights

**Compliance Automation Tier (Vanta/Drata/Secureframe):**
- Primary revenue driver: **framework count + headcount tiers**
- Secondary: add-on modules (Trust Center, Vendor Risk)
- Hidden growth: renewal uplifts tied to employee growth
- Average revenue per customer: $15K-$25K/year

**Enterprise GRC Tier (ServiceNow/MetricStream/Archer):**
- Primary revenue driver: **module count + user count**
- Secondary: professional services (often 1-2x license cost)
- Hidden growth: implementation complexity driving consulting
- Average revenue per customer: $150K-$500K/year

**AI Governance Tier (Credo/Arthur/Fiddler):**
- Primary revenue driver: **number of AI use cases/models governed**
- Secondary: enterprise features (VPC, SSO, SLAs)
- Hidden growth: regulatory complexity (EU AI Act)
- Average revenue per customer: $30K-$150K/year
